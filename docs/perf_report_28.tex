\begin{abstract}
Report~27 admitted only pixel-identical changes to the grass seam and found
15; twelve landed exactly as specified (commits \texttt{06df5e37} through
\texttt{ee29528d}: union fast path, unblended veg color, batched capture,
material-only tint, submit elision, flat trig, and the hygiene tail). Three
were skipped as specified-plus-validation: the SDF frame table (callees take
\texttt{SdfInstance} by value with no index), the vertex-invariant table
(new compute, new attributes, unowned files), and the twin folding (build
plumbing plus deliberate edge differences). This report re-iterates the same
scope under the same gate (\S\ref{sec:gate27}, unchanged) and finds what is
genuinely left: buildable specifications for all three skipped items ---
with the index-threading, binding numbers, and file lists the handoffs asked
for --- plus one new bandwidth win the re-audit surfaced (two-tier
turbulence reject) and three exact micro-items (smoothK hoist, twin
placement include with dead-varying cleanup, push-invariance trivia).

It finds \textbf{7 issues} (2 critical, 1 high, 3 medium, 1 low), all
pixel-identical by construction with an A/B gate each. Scope score
\textbf{6.4/10}; folding into the combined estimate at 10\% weight gives
\textbf{6.0/10}.
\end{abstract}

\subsection{C1: SDF Frame Table, Buildable Specification (Skipped 27-C1)}
\label{sec:c1}

\textbf{Severity: Critical.}

Report~27's C1 stands unimplemented: every candidate evaluation rebuilds
\texttt{sdfEulerMat} twice (6 trig + 2 matmuls,
\texttt{SdfOps.glsl:101--118}) inside \texttt{sdfModelToLocal} and the
wind lean (\texttt{SdfRenderer.frag:183--202}), plus a wind-lean field
sample on each 4-entry-cache miss (\texttt{:788--814}), plus a third
construction in \texttt{sdfModelDirToLocal} where used
(\texttt{SdfModel.glsl:37--49}) --- $\sim$150 flops of setup per candidate
per step for genuinely nontrivial rotations
(\texttt{SdfScene.cpp:722}). The skip rationale is now precise rather than
blocking: the evaluators take \texttt{SdfInstance} \emph{by value with no
index} (\texttt{sdfEvalInstance} at \texttt{SdfRenderer.frag:214},
\texttt{sdfSurfaceNormal} at \texttt{:327},
\texttt{sdfSurfaceNormalFD} at \texttt{:353},
\texttt{sdfGrassShadowEval} at \texttt{SdfGrassShadow.frag:128}), so no
callee can address a table row today. The buildable path: thread the
instance index (callers already hold it --- march \texttt{ii} at
\texttt{SdfRenderer.frag:783}, shadow \texttt{ii} at
\texttt{SdfGrassShadow.frag:207}; normals track best-by-value today and
gain a best-index alongside) and read a per-frame table row instead of
rebuilding. Table contents, all frame-invariant per instance: euler mat3,
translation, per-axis scale, min-axis scale, lean vec2 + amplitude
(\texttt{windSVF} at the instance origin, already per-instance by
construction), plus \texttt{camScale} and the min-axis out-scale (both
functions of frame uniforms + instance data only, same \texttt{sqrt} the
march runs today). New \texttt{binding = 11} in set 1 (the layout declares
\texttt{bindings[11]}, indices 0--10:
\texttt{SdfRenderer.cpp:183}, smoke at 8, profile at 10), filled by a new
\texttt{.comp} (auto-discovered by the \texttt{Makefile}) dispatched after
\texttt{recordSlotCopies} on the same queue; extend the set-1 layout with
the COMPUTE stage bit for the fill. Then delete the per-ray wind cache
arrays. Same GLSL expressions, same frame time, same order: bit-identical,
gated by A/B.

\begin{tcolorbox}[promptbox={Prompt --- C1: SDF frame table with index threading}]
Goal: transform setup once per instance per frame. Steps: (1) thread the
instance index through the four evaluators (callers hold it; normals gain a
best-index); (2) add the table at set-1 binding 11 with the contents above,
filled by a per-frame compute using verbatim shader expressions;
(3) rewrite the three euler constructions + lean + camScale reads to table
reads; (4) delete the ray wind cache; (5) extend set-1 with COMPUTE usage
for the fill only. Files: \texttt{shaders/renderer/sdf/SdfRenderer.frag},
\texttt{shaders/includes/sdf/SdfModel.glsl},
\texttt{shaders/renderer/shadow/SdfGrassShadow.frag},
\texttt{vulkan/renderer/sdf/SdfRenderer.cpp/.hpp}, new \texttt{.comp}.
Validation: pixel-identical A/B on march-heavy views in both grass modes,
validation-clean (watch the new binding's stage flags and the fill/draw
ordering).
\end{tcolorbox}

\subsection{C2: Vertex-Invariant Table, Buildable Specification (Skipped 27-C3)}
\label{sec:c2}

\textbf{Severity: Critical (wind stays per-vertex, as proven).}

Report~27's C3 stands unimplemented with its boundary verified, not just
stated: \texttt{applyWindSkew} samples at per-\emph{corner} positions
(\texttt{worldPos + localPos}, \texttt{VegetationRenderer.vert:221})
through position-dependent Perlin and tornado cores
(\texttt{WindField.glsl:100--108}), so center-sampling changes values and
wind stays per-vertex forever. Everything around it is frame-invariant per
instance and still runs per corner per pass (depth + color + 3 cascades;
color + depth + cascades on impostors): \texttt{cosT/sinT}
(\texttt{VegetationRenderer.vert:194--196}), normalized surfN + Rodrigues
tilt basis (\texttt{:228--232}), best layer (shared helper, still
per-vertex by contract), impostor \texttt{toCamera}, plus
\texttt{quadHalfW/H} and \texttt{billboardScale * hs} (pure instance
functions). Vehicle, fully specified: a dedicated per-instance compute per
frame (the merged cull emits per-\emph{chunk} commands,
\texttt{IndirectRenderer.comp:282--303}, so it cannot host this; bake
precedent stands) writing a device-local row consumed as a new
instance-rate buffer (binding index 3; bindings 0--2 are vertex/instance/aux
per the pipeline creation, and attribute location 9, \texttt{ATTR\_},
is free: \texttt{locations.hpp} uses 0--8). All four vertex stages
(billboard, billboard shadow, both impostor twins) read the row; corner
math, wind, and placement stay byte-identical. Same expressions, same
frame clock and UBO revision: bit-identical, gated by A/B with wind held
constant.

\subsection{H3: Two-Tier Turbulence Reject With a CPU Max Bound (New)}
\label{sec:h3}

\textbf{Severity: High.}

The main march fetches the material \emph{before} the AABB test
(\texttt{SdfRenderer.frag:719--730}) for exactly one reason: the widened
accept radius \texttt{skipR = maxStep + 0.1 + abs(m0.turbulence)}
(\texttt{:726}). But turbulence is a tiny known set: grass and rock
materials carry 0.0 (\texttt{SdfScene.cpp:530}, grass \texttt{turbulence =
0.0}), fire/smoke carry 0.6 (\texttt{:383,432,496,614}; struct default 0.6,
\texttt{SdfMaterial.hpp:34}). A CPU max-scan over the merged materials at
\texttt{refreshMergedLocked} time yields an exact bound, streamed through
the existing params-dirty path, enabling two tiers with identical
decisions: tier 1 rejects \texttt{ob > maxStep + 0.1 + maxTurb} with
\emph{no} material fetch (beyond the bound no material could accept);
tier 2 fetches and runs the exact \texttt{skipR} test. Far rejects ---
the common case, the reason the pre-test exists --- skip a $\sim$100\,B
material SSBO load each. The bound is conservative by construction, and
the tint-only path (which never touches turbulence) reuses the last scan.
The load-bearing part is the bound, not the reorder: gating the fetch on
anything weaker than the true maximum would mis-reject.

\begin{tcolorbox}[promptbox={Prompt --- H3: max-turbulence two-tier reject}]
Goal: far rejects skip the material fetch. Steps: (1) CPU max-scan of
\texttt{|turbulence|} over merged materials at merge time into a params
field; (2) tier-1 reject above \texttt{maxStep + 0.1 + bound} with no
fetch, tier-2 exact test after fetch; (3) re-scan on structural rebuilds,
reuse on material-only patches. Files:
\texttt{shaders/renderer/sdf/SdfRenderer.frag},
\texttt{sdf/types/SdfScene.cpp},
\texttt{vulkan/renderer/sdf/SdfRenderer.cpp},
\texttt{vulkan/ubo/SdfParamsUBO.hpp}. Validation: pixel-identical A/B
including smoke-heavy views, material-load counters down,
validation-clean.
\end{tcolorbox}

\subsection{M4: smoothK Unpack Runs on the Union Path That Ignores It}

\textbf{Severity: Medium.}

Since the C2-union landing, both marches compute
\texttt{float kk = clamp(sdfUnpackSmoothK(dd), 0.0, 2.0)} for \emph{every}
evaluated candidate (\texttt{SdfRenderer.frag:828},
\texttt{SdfGrassShadow.frag:260}) and then ignore it on the union arm.
\texttt{sdfUnpackSmoothK} is a bare field read
(\texttt{SdfMaterial.glsl:21}), so the saving is one unpack plus one clamp
per candidate per step on the union path --- small per unit, multiplied by
steps $\times$ candidates $\times$ covered pixels. Move the unpack into the
non-union arm (identical values where read; unread where dropped).

\begin{tcolorbox}[promptbox={Prompt --- M4: unpack smoothK only off the union path}]
Goal: union candidates skip one unpack+clamp each. Steps: (1) compute
\texttt{kk} inside the non-union branch in both marches; (2) keep the
\texttt{haveBest} first-take and the dispatch untouched. Files:
\texttt{shaders/renderer/sdf/SdfRenderer.frag},
\texttt{shaders/renderer/shadow/SdfGrassShadow.frag}. Validation:
pixel-identical A/B, validation-clean.
\end{tcolorbox}

\subsection{M5: Twin Placement Include and Dead Varying Decls (Skipped 27-L13, Re-Specified)}

\textbf{Severity: Medium (maintenance first, micro second).}

Full \texttt{-D} folding stays out (build plumbing plus deliberate edge
differences, per the skip), but the re-audit narrows the safe core: the
placement blocks (center $\rightarrow$ quad $\rightarrow$ offset
$\rightarrow$ finalPos $\rightarrow$ UV crop) of
\texttt{VegetationRendererImpostor.vert} and
\texttt{VegetationRendererImpostorDepth.vert} are textually identical, while

go). Negligible ALU either way; stated honestly as drift prevention plus
freed interpolator slots.

\subsection{M6: Loop-Invariant Push Batching (Capture PC, Shadow Time)}

\textbf{Severity: Medium (load-time and idle-path trivia, exact).}

\subsection{L7: Pack the Shadow Step Count Into the March Vec4}

\texttt{vShadowMaxSteps} rides its own flat int varying (location 17)
while \texttt{vShadowMarch} carries four floats at location 16
(\texttt{SdfGrassShadow.vert}, report~27 M10). Step counts never exceed 256,
exactly representable in float; carrying the count in the vec4's exact
integral value and converting back with \texttt{int(x + 0.5)} reproduces
the identical integer and frees an interpolator slot. Trivia, stated as
trivia: same value, one fewer location.

\section{Deliberately Unchanged}
\label{sec:unchanged28}

Carried from reports~26--27 (ladders, tiers, thinning, footprint LOD,
resolutions, prepass overlap semantics, shared-EVSM shadow elision,
per-corner wind, clocks, rounding-boundary crossings, frustum compaction,
stride floor, subgroup broadcast): still quality knobs or rounding changes,
still excluded. Four traps this re-audit caught, recorded so they stay
caught:

\begin{itemize}[leftmargin=1.4em,itemsep=2pt]
\item \textbf{Squared-distance AABB compare.} Replacing
\texttt{length(oq) > skipR} with \texttt{dot(oq,oq) > skipR*skipR} saves a
sqrt per candidate but is \emph{not} bit-identical: \texttt{fl(s*s)}
rounding can flip the decision exactly at the boundary. H3's CPU max bound
is the exact way to skip the fetch, not the sqrt.
\item \textbf{CPU-side light-direction normalize.} Hoisting
\texttt{normalize(-ubo.lightDirection)} to the CPU (glm) re-rounds vs the
GPU path; the H8 flat varying (GPU, same op) is the exact form. Same reason
CPU TRS precompute stays out.
\item \textbf{Unbinding the profile-counters buffer (27-L14 residual).}
Post-push the bound-but-unread buffer costs zero loads; conditional unbind
needs descriptor/layout surgery for no gain. Retired, not deferred.
\item \textbf{Impostor cull-source asymmetry.} The color twin culls on
\texttt{ubo.viewPosition}, the depth twin on
\texttt{windParams.cameraPosition} (same camera by construction, different
sources). Unifying either side alters cull sets if they ever diverge;
without evidence of divergence this is not an exact change. Left as-is,
prologues stay separate (M5).
\end{itemize}
